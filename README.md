# 🚀 Portfólio Single Page

Aplicação web desenvolvida para apresentação profissional, estruturada como uma Single Page Application (SPA).

Esta versão representa o **MVP (Minimum Viable Product)** do projeto.

---

## 📌 Sobre o Projeto

O objetivo deste sistema é apresentar de forma clara e organizada:

- Informações profissionais  
- Trajetória acadêmica  
- Projetos desenvolvidos  
- Contato  

O projeto é versionado e estruturado para permitir evolução contínua.

---

## 🛠 Tecnologias Utilizadas (Versão Atual)

- React  
- CSS  

> Esta seção descreve apenas as tecnologias presentes na versão atual do sistema.
